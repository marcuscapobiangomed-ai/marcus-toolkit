# Protocolo Mandatório: Deep Code Sweep (Varredura Cirúrgica & Auditoria Profunda)

Sempre que realizar varreduras, auditorias ou inspeções aprofundadas em uma área, módulo ou subsistema do projeto:
1. **Linha a Linha & Rastreamento de Fluxos:** Inspecione cada linha de código sem superficialidades, rastreando fluxo de entrada, chamadas assíncronas, tratamento de exceções, mutações de estado e saídas.
2. **Integrações & Efeitos Colaterais:** Mapeie todas as conexões com outras seções do projeto, validando contratos de dados e identificando acoplamentos indevidos ou efeitos colaterais silenciosos.
3. **Catálogo Exaustivo de Achados:** Registre todas as falhas/bugs, brechas de segurança, débitos técnicos, ideias de melhorias e aprimoramentos de performance e UX.
4. **Contexto Global & Deep Problem Solver:** Avalie o impacto no ecossistema completo e submeta as falhas críticas e decisões arquiteturais ao protocolo mandatório do Deep Problem Solver (Anatomia -> Causas Exaustivas -> Soluções Divergentes -> Convergência Holística).
5. **Dossiê Executivo de Entrega:** Estruture a entrega com matriz de achados categorizada, dissecção aprofundada dos pontos críticos e plano tático priorizado de execução.
