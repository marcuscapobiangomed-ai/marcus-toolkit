# Protocolo Mandatório: Deep Problem Solver

Sempre que diagnosticar bugs, avaliar ideias, propor novas funcionalidades ou realizar correções:
1. **Foco Isolado:** Aprofunde-se no problema (sempre um de cada vez, sem misturar múltiplos escopos).
2. **Exaustão de Causas:** Mapeie todas as causas possíveis (dados de entrada, lógica de backend, interface/UX e arquitetura sistêmica).
3. **Divergência de Soluções:** Formule e compare todas as soluções possíveis (da mínima/rápida à autônoma/robusta).
4. **Visão Holística:** Escolha e justifique a solução mais recomendada ponderando a estabilidade, harmonia visual, integridade científica e performance de todo o sistema.
